# 2026년 2학기 창의공학설계 첫 번째 프로젝트

## 프로젝트 소개 
 이 프로젝트는 2026년 2학기 창의공학설계 과목을 수강하면서 진행 할 첫 번째 프로젝트의 모든 과정을 작성하기 위한 공간입니다. 
 이번 프로젝트에서는 어떠한 기능을 하는 챗봇을 만들려고 합니다. 챗봇을 만들며 바이브 코딩에 대한 이해도와 프로젝트 숙련도를 높이겠습니다.

## 만들고 싶은 이유
 무언가를 먹고 싶을 때 메뉴를 고민하는데 많은 시간을 소비한 경험이 있다. 이러한 경우는 반복적으로 나타나고 고민하는 시간은 적지않다. 
 그렇기에 이런 고민하는 시간을 줄이기 위해 나의 기분과 상황을 고려하여 메뉴 추천을 해주는 챗봇을 제작할 생각이다. 
 이 챗봇을 통해 메뉴를 고민하는 시간을 줄일 수 있고, 챗봇이 추천해주는 뜻밖에 메뉴를 통해 소소한 행복도 누릴 수 있을 것이라 기대된다.
