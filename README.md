# 2026년 2학기 창의공학설계 첫 번째 프로젝트

## 프로젝트 소개 
 이 프로젝트는 2026년 2학기 창의공학설계 과목을 수강하면서 진행 할 첫 번째 프로젝트의 모든 과정을 작성하기 위한 공간입니다. 
 이번 프로젝트에서는 어떠한 기능을 하는 챗봇을 만들려고 합니다. 챗봇을 만들며 바이브 코딩에 대한 이해도와 프로젝트 숙련도를 높이겠습니다.

## 만들고 싶은 이유
 우리가 사용하는 챗봇은 다소 사무적인 말투가 기본으로 깔려있기에 가벼운 이야기를 하기에는 좋은 상대가 되지 못합니다. 
 이러한 문제를 해결하기 위해 보다 친근한 분위기의 말투를 학습시켜 친구와 같은 챗봇을 만들고 싶습니다. 
 요즘같이 1인 가구가 늘어나고, 주로 개인적인 분위기의 사회가 되어 다양한 사람들과의 접촉이 줄게 되었고, 우울증과 같은 정신적인 질환의 환자가 늘었다고 알고있습니다.
 제가 만들 친근한 챗봇이 이러한 문제점을 해결할 수 있을거라 생각해 만들고 싶습니다.
